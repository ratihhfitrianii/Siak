🔐 Login & Antarmuka Utama

Cara masuk ke sistem dan mengenal antarmuka SIAK
1

Cara Login ke Sistem

Buka halaman login SIAK di browser Anda. Masukkan NIM (mahasiswa), NIK (dosen), atau email (admin) beserta password Anda.

  1. Buka halaman login di https://siak-vercel.vercel.app/login
  2. Masukkan NIM / NIK / Email pada kolom pertama
  3. Masukkan Password pada kolom kedua
  4. Klik tombol 「Masuk」
  5. Anda akan diarahkan ke Dashboard sesuai peran Anda
💡 Tips: Akun mahasiswa/dosen menggunakan email institusi. Hubungi Admin Sistem bila lupa password.
Halaman Login SIAK
2

Antarmuka Utama — Sidebar & Dashboard

Setelah login, Anda akan melihat Dashboard sebagai halaman utama. Di sebelah kiri terdapat Sidebar berisi menu navigasi yang berbeda untuk setiap peran.

  • Dashboard — Ringkasan informasi dan akses cepat ke fitur utama
  • Sidebar — Menu navigasi di sebelah kiri layar
  • Profil Pengguna — Ikon profil di pojok kanan atas
Peran Menu yang Tersedia
Mahasiswa Profil, Hasil Studi, KRS, Virtual Absensi, Jadwal Kuliah, Keuangan, Skripsi
Dosen Pilih MK, Jadwal, Absensi, Bimbingan, Nilai, Slip Gaji, Profile
Admin Akademik User, Master, Jadwal, Persetujuan MK, Ajuan Proposal, Master Akademik
Admin Keuangan Tagihan, Daftar Gaji
Admin Sistem User, Master, Informasi Penting

🎓 Panduan Mahasiswa

Fitur-fitur yang tersedia untuk mahasiswa
Profil KHS / Transkrip KRS Absensi Jadwal Keuangan Skripsi
1

Dashboard Mahasiswa

Dashboard menampilkan ringkasan informasi akademik mahasiswa, termasuk status KRS, informasi pembayaran, pengumuman terbaru, dan akses cepat ke menu yang sering digunakan.

  • Ringkasan status KRS semester aktif
  • Informasi pembayaran (lunas/belum lunas)
  • Pengumuman terbaru dari admin
  • Akses cepat ke fitur utama
Dashboard Mahasiswa — Ringkasan informasi akademik
2

Profil Saya

Halaman profil menampilkan data diri mahasiswa secara lengkap. Anda dapat melihat dan mengunduh E-KTM, serta mengubah informasi kontak (nomor HP, email pribadi, alamat domisili).

  • Foto profil dan nama lengkap
  • Data akademik: NIM, Program Studi, Fakultas, Angkatan, Jalur Masuk, Status
  • Email kampus
  • Download E-KTM
  • Edit kontak: No. HP, Email Pribadi, Alamat Domisili
💡 Tips: Klik tombol "Edit" pada bagian Kontak & Domisili untuk mengubah informasi kontak Anda.
Profil Mahasiswa — Data diri dan kontak
3

Kartu Hasil Studi (KHS)

KHS menampilkan daftar mata kuliah beserta nilai yang diperoleh pada semester tertentu. Anda dapat melihat transkrip nilai dan mengunduhnya dalam format PDF.

  • Daftar mata kuliah per semester
  • Nilai huruf dan nilai angka (IP)
  • Jumlah SKS semester
  • IPS (Indeks Prestasi Semester) dan IPK (Indeks Kumulatif)
  • Download transkrip dalam format PDF
Kartu Hasil Studi (KHS) — Transkrip nilai semester
4

Riwayat Studi

Riwayat Studi menampilkan grafik perkembangan IPS dari semester ke semester, termasuk grafik bar chart IPS per semester dan ringkasan IPK kumulatif.

  • Grafik bar chart IPS per semester
  • Ringkasan IPK kumulatif
  • Total SKS yang telah ditempuh
  • Jumlah semester aktif
Riwayat Studi — Grafik IPS dan ringkasan IPK
5

Pemrograman KRS (Kartu Rencana Studi)

KRS digunakan untuk memilih mata kuliah yang akan diambil pada semester depan. Pastikan pembayaran sudah lunas sebelum mengisi KRS.

  • Daftar mata kuliah yang tersedia sesuai kurikulum
  • Pilihan kelas per mata kuliah
  • Informasi kapasitas dan jumlah terisi
  • Status KRS: Draft → Submitted → Approved
  • Download KRS dalam format PDF
⚠️ Perhatian: KRS hanya bisa diisi jika pembayaran semester sudah LUNAS. Pastikan status pembayaran Anda lunas sebelum periode KRS dibuka.
Pemrograman KRS — Pilih mata kuliah semester depan
6

Kurikulum

Halaman Kurikulum menampilkan daftar lengkap semua mata kuliah yang pernah dan akan dikontrak sesuai kurikulum program studi Anda.

  • Daftar lengkap mata kuliah kurikulum
  • Informasi SKS per mata kuliah
  • Status: Sudah Ditempuh / Belum
  • Nilai untuk mata kuliah yang sudah ditempuh
Kurikulum — Daftar lengkap mata kuliah program studi
7

Virtual Absensi (Check-in)

Fitur absensi online untuk mahasiswa. Anda dapat melakukan check-in kehadiran dengan memasukkan ID Sesi atau memindai QR Code yang ditampilkan oleh dosen.

  1. Buka halaman Virtual Absensi dari sidebar
  2. Masukkan ID Sesi yang diberikan dosen, atau
  3. Gunakan QR Code yang ditampilkan dosen di kelas
  4. Klik Check-in untuk mencatat kehadiran
💡 Info: ID Sesi ditampilkan pada kartu kelas di halaman Jadwal Dosen. Pastikan Anda memasukkan ID yang benar untuk kelas yang sedang berlangsung.
Virtual Absensi — Check-in kehadiran kelas
8

Jadwal Kuliah

Menampilkan jadwal kuliah mingguan untuk semua kelas yang Anda ikuti, lengkap dengan informasi hari, jam, ruangan, dan dosen pengampu.

  • Jadwal mingguan: Senin — Sabtu
  • Informasi mata kuliah, kelas, dan dosen
  • Waktu dan ruangan per kelas
  • Status presensi per pertemuan
Jadwal Kuliah — Jadwal mingguan kelas
9

Keuangan — Tagihan Saya

Menampilkan detail tagihan pembayaran kuliah per semester, termasuk jumlah tagihan, status pembayaran, dan tanggal jatuh tempo.

  • Detail tagihan per semester
  • Jumlah tagihan total
  • Status: Lunas / Belum Lunas
  • Tanggal jatuh tempo
Tagihan Saya — Detail pembayaran per semester
10

Keuangan — Riwayat Pembayaran

Riwayat pembayaran menampilkan semua transaksi pembayaran yang pernah Anda lakukan, termasuk bukti upload pembayaran.

  • Riwayat semua pembayaran
  • Status pembayaran per semester
  • Bukti upload pembayaran
  • Detail jumlah bayar
Riwayat Pembayaran — Semua transaksi pembayaran
11

Skripsi — Ajukan Bimbingan

Fitur untuk mengajukan proposal skripsi dan bimbingan. Mahasiswa dapat memilih maksimal 2 dosen pembimbing dan mengupload file proposal.

  1. Isi judul skripsi
  2. Pilih dosen pembimbing (maksimal 2 orang) menggunakan fitur pencarian
  3. Upload file proposal skripsi
  4. Klik 「Ajukan」 untuk mengirim proposal
  5. Pantau status: Diajukan → Diterima / Ditolak
💡 Tips: Gunakan fitur pencarian pada kolom dosen pembimbing untuk menemukan dosen yang diinginkan. Pilih dosen sesuai bidang keahlian Anda.
Ajukan Bimbingan — Form pengajuan proposal skripsi
12

Skripsi — Sidang

Fitur pendaftaran sidang skripsi. Halaman ini tersedia untuk mahasiswa yang status bimbingannya sudah disetujui dan siap untuk sidang.

Sidang Skripsi — Pendaftaran sidang

👨‍🏫 Panduan Dosen

Fitur-fitur yang tersedia untuk dosen pengampu
Pilih MK Jadwal Substitute Absensi Bimbingan Nilai Slip Gaji
1

Dashboard Dosen

Dashboard dosen menampilkan ringkasan kelas yang diampu, jumlah mahasiswa, jadwal mengajar hari ini, dan akses cepat ke fitur utama dosen.

  • Ringkasan kelas yang diampu
  • Jumlah mahasiswa aktif
  • Jadwal mengajar hari ini
  • Statistik kehadiran
Dashboard Dosen — Ringkasan kelas dan jadwal
2

Pilih Mata Kuliah

Halaman untuk memilih mata kuliah yang akan diampu. Dosen dapat melihat daftar mata kuliah yang tersedia berdasarkan program studi dan mengklaim kelas yang diinginkan.

  • Filter mata kuliah berdasarkan program studi
  • Lihat kapasitas dan jumlah terisi
  • Klaim kelas (ambill mengajar)
  • Batalkan klaim kelas
Pilih Mata Kuliah — Pilih kelas yang akan diampu
3

Jadwal — Rencana Mengajar

Menampilkan jadwal mengajar dosen dalam format kalender mingguan. Panel kiri menampilkan daftar kelas, panel kanan menampilkan grid kalender mingguan dengan blok warna untuk setiap kelas.

  • Panel Kiri: Daftar kelas dengan indikator status (hijau/merah)
  • Panel Kanan: Kalender mingguan (Senin-Sabtu, 07:00-18:00)
  • Blok warna pastel untuk setiap mata kuliah
  • Informasi ruangan dan jam per kelas
  • Status: Draft / Proses / Disetujui
💡 Info: Blok pada kalender berdasarkan jadwal waktu (time slot) yang ditetapkan Kaprodi, bukan jumlah pertemuan. Kelas yang belum terjadwal tidak akan muncul di kalender.
Rencana Mengajar — Kalender jadwal mingguan dosen
4

Jadwal — Substitute

Fitur penggantian jadwal mengajar. Dosen dapat mengajukan substitusi ketika tidak bisa mengajar pada jadwal tertentu.

Substitute — Penggantian jadwal mengajar
5

Absensi — Kelola Absensi

Dosen dapat membuat sesi absensi, membuka/menutup sesi, dan mengelola kehadiran mahasiswa per pertemuan.

  1. Pilih kelas yang akan diabsen
  2. Buat sesi absensi baru (POST /attendance/sessions)
  3. Buka sesi agar mahasiswa bisa check-in
  4. Lihat daftar kehadiran mahasiswa secara real-time
  5. Update status kehadiran manual jika diperlukan
  6. Tutup sesi setelah pertemuan selesai
💡 Tips: Setiap sesi absensi memiliki ID unik. ID ini ditampilkan pada kartu kelas sehingga mahasiswa tahu ID yang harus dimasukkan saat check-in.
Kelola Absensi — Buat dan kelola sesi kehadiran
6

Absensi — Rekap Kehadiran Mahasiswa

Menampilkan persentase kehadiran setiap mahasiswa di setiap kelas yang diampu. Berguna untuk memantau tingkat kehadiran mahasiswa secara keseluruhan.

  • Persentase kehadiran per mahasiswa
  • Filter per kelas
  • Detail jumlah hadir, izin, sakit, tidak hadir
Rekap Kehadiran — Persentase kehadiran mahasiswa
7

Bimbingan — Pengajuan Proposal

Dosen pembimbing dapat melihat dan mereview proposal skripsi yang diajukan mahasiswa binaan. Dosen dapat menyetujui atau menolak proposal beserta catatan.

  • Daftar proposal skripsi yang perlu direview
  • Detail proposal: judul, file, status
  • Action: Setujui / Tolak dengan catatan
  • Riwayat review proposal
Pengajuan Proposal — Review proposal skripsi mahasiswa
8

Bimbingan — Mahasiswa Binaan

Daftar mahasiswa yang sedang dalam proses bimbingan (status: dalam_bimbingan, siap_sidang). Dosen dapat mencatat progres bimbingan untuk setiap mahasiswa.

  • Daftar mahasiswa aktif dalam bimbingan
  • Status: Dalam Bimbingan / Siap Sidang
  • Catat bimbingan (tanggal, catatan)
  • Lihat riwayat bimbingan
⚠️ Perhatian: Mahasiswa dengan status lulus tidak ditampilkan pada daftar ini dan tombol "Catat Bimbingan" dinonaktifkan.
Mahasiswa Binaan — Daftar dan catat bimbingan
9

Input & Edit Nilai

Dosen dapat menginput dan mengubah nilai mahasiswa untuk kelas yang diampu. Nilai meliputi tugas, UTS, UAS, dan nilai akhir.

  • Input nilai baru (POST /grades)
  • Edit nilai yang sudah ada (PUT /grades/:id)
  • Komponen nilai: Tugas, UTS, UAS, Final Score
  • Nilai huruf dan grade point otomatis
  • Atribusi input_by (dosen yang menginput)
Input Nilai — Kelola nilai mahasiswa
10

Slip Gaji

Dosen dapat melihat dan mengunduh slip gaji per periode (bulan/tahun). Slip gaji tersedia dalam format PDF.

  • Filter slip gaji per bulan dan tahun
  • Detail komponen gaji
  • Download slip gaji PDF
  • Riwayat slip gaji
Slip Gaji — Lihat dan unduh slip gaji dosen
11

Profil Dosen

Halaman profil dosen menampilkan data diri, foto profil, dan informasi kontak. Dosen dapat mengubah foto profil dan informasi kontak.

  • Foto profil dan nama lengkap
  • Informasi akademik: NIDN, NIK, Program Studi
  • Edit foto profil
  • Edit informasi kontak
Profil Dosen — Data diri dan pengaturan profil

🏛️ Panduan Admin Akademik

Fitur-fitur pengelolaan data akademik
User Management Master Data Jadwal Persetujuan MK Proposal Skripsi Master Akademik
1

Dashboard Admin Akademik

Dashboard admin akademik menampilkan ringkasan data akademik, jumlah mahasiswa aktif, dosen, dan status operasional sistem.

Dashboard Admin Akademik — Ringkasan data akademik
2

Kelola Pengguna (User)

Kelola data pengguna sistem: mahasiswa, dosen, dan admin lainnya. Admin akademik hanya dapat mengelola pengguna di fakultas yang dikepalainya.

  • + Buat User — Tambah pengguna baru
  • Cari — Pencarian berdasarkan nama atau email
  • Filter — Filter berdasarkan peran (role)
  • Ubah Peran — Ganti peran pengguna
  • Hapus — Hapus pengguna dari sistem
  • Status — Aktif / Non-aktif
⚠️ Batasan: Admin akademik hanya bisa mengelola pengguna di fakultas yang terikat. Maksimal 3 admin akademik per fakultas.
Kelola Pengguna — CRUD pengguna sistem
3

Master Data — Fakultas & Program Studi

Kelola data master fakultas dan program studi. Tersedia dalam format tab terpisah untuk kemudahan navigasi.

  • Tab Fakultas: Daftar fakultas dengan CRUD
  • Tab Prodi: Daftar program studi per fakultas
  • Tambah, edit, hapus data fakultas dan prodi
  • Status aktif/non-aktif
Master Fakultas & Prodi — Pengelolaan data akademik
4

Jadwal Pengajar

Kelola jadwal pengajar per kelas. Admin akademik dapat menetapkan dosen pengampu dan mengatur waktu/kota pengajaran.

  • Daftar kelas per semester
  • Assign dosen ke kelas
  • Atur jadwal waktu (hari, jam, ruangan)
  • Monitor kapasitas kelas
Jadwal Pengajar — Kelola jadwal per kelas
5

Persetujuan Mata Kuliah Dosen

Review dan setujui/tolak pilihan mata kuliah yang diajukan dosen. Data dikelompokkan berdasarkan dosen dengan status keseluruhan.

  • Data dikelompokkan per dosen (1 baris = 1 dosen)
  • Filter: Semester, Program Studi, Status
  • Detail: Lihat semua MK yang diajukan dosen
  • Action: Setujui / Tolak per MK
  • Pencatatan reviewer dan waktu review
Persetujuan MK — Review pilihan mata kuliah dosen
6

Ajuan Proposal Skripsi

Kelola semua proposal skripsi mahasiswa. Admin akademik dapat melihat, menyetujui, atau menolak proposal yang masuk.

  • Daftar semua proposal skripsi
  • Filter berdasarkan status
  • Detail proposal: judul, mahasiswa, dosen pembimbing
  • Action: Setujui / Tolak dengan catatan
Ajuan Proposal — Review proposal skripsi mahasiswa
7

Master Akademik

Kelola data master akademik termasuk Ruangan, Program Studi per Fakultas, dan Mata Kuliah.

  • Tab Ruangan: Daftar ruangan kampus
  • Tab Prodi per Fakultas: Pemetaan prodi ke fakultas
  • Tab Mata Kuliah: Daftar matakuliah global
  • CRUD untuk semua master data
Master Akademik — Ruangan, Prodi, Mata Kuliah

💰 Panduan Admin Keuangan

Fitur pengelolaan keuangan dan pembayaran
Tagihan Pembayaran Gaji Dosen
1

Dashboard Admin Keuangan

Dashboard admin keuangan menampilkan ringkasan data keuangan, jumlah tagihan aktif, status pembayaran mahasiswa, dan data gaji dosen.

Dashboard Admin Keuangan — Ringkasan data keuangan
2

Kelola Tagihan

Kelola tagihan pembayaran mahasiswa. Data ditampilkan terkelompok per NIM (mahasiswa) dengan detail tagihan per semester.

  • Data terkelompok berdasarkan NIM
  • Generate tagihan baru per semester
  • Update status pembayaran (lunas/belum lunas)
  • Fitur "Bayar Semua" untuk update batch
  • Detail tagihan per mahasiswa per semester
  • Upload bukti pembayaran
💡 Info: Status "Lunas" hanya tercapai jika SEMUA semester sudah dibayar. Gunakan "Bayar Semua" untuk update batch beberapa tagihan sekaligus.
Kelola Tagihan — Data terkelompok per NIM
3

Daftar Gaji Dosen

Generate dan kelola slip gaji dosen. Admin keuangan dapat membuat, menyetujui, dan mencetak slip gaji per periode.

  • Generate slip gaji dosen per periode
  • Live search dosen
  • Sortable columns
  • Pagination 10 data per halaman
  • Bulk approve (rata kanan)
  • Download slip gaji PDF
Daftar Gaji — Generate dan kelola slip gaji dosen

🔧 Panduan Admin Sistem

Superuser — Pengelolaan sistem secara menyeluruh
User Management Master Data Informasi Penting
ℹ️ Catatan: Admin Sistem adalah superuser dengan akses penuh ke semua permission di sistem. Namun, menu sidebar dibatasi hanya untuk: Dashboard, User, Master, dan Informasi Penting.
1

Dashboard Admin Sistem

Dashboard admin sistem menampilkan ringkasan seluruh data sistem, jumlah pengguna aktif, dan status operasional.

Dashboard Admin Sistem — Ringkasan seluruh sistem
2

Kelola Pengguna (User)

Kelola semua pengguna sistem tanpa batasan fakultas. Admin sistem memiliki akses penuh untuk CRUD pengguna, mengubah peran, dan mengatur status aktif/non-aktif.

  • + Buat User — Tambah pengguna baru dengan peran apapun
  • Cari — Pencarian global (tidak dibatasi fakultas)
  • Filter — Filter berdasarkan peran
  • Ubah Peran — Ganti peran pengguna (termasuk admin)
  • Toggle Status — Aktifkan/non-aktifkan pengguna
  • Reset Password — Reset password pengguna
  • Toggle Wali — Atur status wali dosen
Kelola Pengguna — Akses penuh tanpa batasan fakultas
3

Master Data

Kelola data master fakultas dan program studi. Admin sistem memiliki akses penuh untuk semua data master.

  • Kelola semua fakultas
  • Kelola semua program studi
  • CRUD penuh tanpa batasan
Master Data — Kelola fakultas dan program studi
4

Informasi Penting (Pengumuman)

Kelola pengumuman dan informasi penting untuk mahasiswa dan dosen. Pengumuman akan ditampilkan di dashboard pengguna.

  • Buat pengumuman baru
  • Edit pengumuman yang sudah ada
  • Hapus pengumuman
  • Pengumuman ditampilkan di dashboard semua pengguna
Informasi Penting — Kelola pengumuman sistem
